## 📌 About the Project

SmartRecruit AI is a full-stack recruitment platform designed to simplify and streamline the hiring process for candidates, recruiters, and administrators. The platform enables candidates to explore job opportunities, upload resumes, and view skill-based job matching scores, while recruiters can manage job postings and evaluate applicants. An admin dashboard provides centralized management of the platform.

---

## 🚀 Features

### 👤 Candidate
- Candidate registration and login.
- Browse and view job opportunities.
- Upload resumes.
- Resume-based job matching score.
- View matched and missing skills.
- Apply for jobs.
- Track application status.

### 💼 Recruiter
- Recruiter registration and login.
- Post and manage job openings.
- View applicants for posted jobs.
- Review candidate match scores.
- Shortlist and manage applicants.

### 🛡️ Admin
- Admin dashboard.
- Manage candidates and recruiters.
- Manage job postings.
- Monitor applications.
- Centralized platform management.

## ⚙️ Installation and Setup

### 1. Clone the Repository

    git clone YOUR_GITHUB_REPOSITORY_LINK

### 2. Backend Setup

- Navigate to the Spring Boot backend project.
- Configure MySQL database connection details in `application.properties`.
- Run the Spring Boot application.

### 3. Frontend Setup

- Navigate to the frontend directory.
- Install dependencies:

      npm install

- Start the development server:

      npm run dev
